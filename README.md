## 📋 Sobre o Projeto

Este projeto foi desenvolvido durante uma aula do **Mayk Brito** na **Rocketseat**, seguindo o passo a passo do curso. A landing page apresenta a marca fictícia **Snitap Patins**, com um design moderno, animações suaves e layout responsivo.

O projeto explora conceitos avançados de CSS, incluindo animações, gradientes animados, transições suaves e uma estrutura bem organizada de estilos.

## ✨ Funcionalidades

- 🎨 **Design Moderno**: Interface clean e atrativa com gradientes vibrantes
- 🌀 **Animações CSS**: Elementos animados que dão vida à página
- 📱 **Layout Responsivo**: Adaptável a diferentes tamanhos de tela
- 🎭 **Texto Rotativo**: Título principal com palavras que alternam automaticamente
- 🎪 **Banner Animado**: Faixa com rolagem infinita e gradiente animado
- 🖼️ **Galeria de Fotos**: Seção com imagens de usuários e animações escalonadas
- 🎯 **Navegação Intuitiva**: Menu superior e rodapé com links para redes sociais

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página
- **CSS3**: Estilização e animações
  - Custom Properties (Variáveis CSS)
  - Flexbox e Grid Layout
  - Animations e Keyframes
  - Gradientes lineares e radiais
  - Transformações 2D
- **Google Fonts**: Tipografias Inter, Montserrat e Syne

## 🎨 Seções da Página

### 1. Header/Navegação Superior

- Logo da marca
- Ícone de sacola de compras com contador

### 2. Hero Section

- Título principal com texto rotativo animado
- Botões de call-to-action:
  - "Comprar Agora"
  - "Veja em Ação"
- Imagem do produto (patins) com elementos decorativos animados

### 3. Banner Animado

- Faixa com rolagem infinita
- Gradiente animado de fundo
- Repetição do logotipo

### 4. Galeria de Fotos

- Grid de imagens de usuários
- Hashtag #usesnitap
- Animações escalonadas (stagger animation)
- Informações do usuário em cada foto

### 5. Footer/Rodapé

- Logo e nome da marca
- Links de navegação
- Ícones de redes sociais

## 💻 Como Executar o Projeto

1. **Clone o repositório ou baixe os arquivos**

```bash
git clone <url-do-repositorio>
```

2. **Navegue até a pasta do projeto**

```bash
cd LP_de_patins_animada
```

3. **Abra o arquivo index.html no navegador**
   - Clique duas vezes no arquivo `index.html`, ou
   - Use um servidor local (como Live Server no VS Code), ou
   - Arraste o arquivo para o navegador
